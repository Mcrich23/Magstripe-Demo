Anatomy of the swipe

Read left to right. Labels show each field’s character count; • hides card-number characters. Issuer data is shown as read.

B = financial format · Name = LAST/FIRST · Expiry = YYMM · Service = usage rules.

Luhn checks the number’s checksum. Shared fields compares the number, expiration, and service code across Tracks 1 and 2.

Readable ≠ authenticated. This reader sends plain text, and a passing checksum doesn’t prove a card is genuine.

Card numbers are masked. Nothing is saved or sent. Swipes clear after 15 seconds.
