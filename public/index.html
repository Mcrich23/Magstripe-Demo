GET CONNECTED
Plug in. Click. Swipe.
  1. Connect your USB reader.
    Use keyboard / HID keyboard mode. Swiping should type text like a keyboard. Set your keyboard layout to match the reader, usually US English.
  2. Click Start capture.
    Keep this browser window in front. The status tells you when this page is listening; it cannot detect whether a USB reader is connected.
  3. Swipe and explore.
    Keep start/end markers enabled (% or ; and ?). Enable all available tracks. Readers that pause between tracks can use the slower setting under Input options.
Working with payment cards
This demo reads plain-text magnetic stripes. It does not read chips, contactless cards, or barcodes. Encrypted readers need their own integration.
No swipes are sent to the local server or saved by this app. Revealing details displays personal data on screen. Clear between participants. Switching tabs clears the result; leaving the window hides details and pauses capture.
